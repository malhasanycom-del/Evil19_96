# Evil19_96 — Android IPTV Player

Android IPTV player starter built with Kotlin, AndroidX, Media3 ExoPlayer, Room, and OkHttp.

## Current capabilities
- Xtream Codes login and live stream listing.
- Import an M3U/M3U8 playlist by URL.
- HLS playback through Media3 ExoPlayer.
- Local favorites stored with Room.
- Android phone and TV-friendly layout foundations.

## Build
Open this project in Android Studio with JDK 17 and Android SDK 35, or use the GitHub Actions workflow to build a debug APK.

## Limitations
Stalker Portal and local-file playlist import are not implemented yet. This is an initial project build, not a tested release. Use only IPTV sources you are authorized to access.
